# Dublin Extensions Spatial Analysis

## Project Overview
This project focuses on spatial analysis of planning extensions in Dublin using GIS tools and Python.

## Repository Structure
- data     -- Input datasets.
- scripts  –- Python scripts for data processing and spatial analysis.
- outputs  -– Generated maps, figures, and results.

## Coordinate Reference System (CRS)
The project will use Irish Transverse Mercator (ITM), EPSG:2157, where appropriate for spatial analysis.

## Data Sources and Licences


## Workflow
The planned workflow is to collect the data, prepare it using Python scripts, perform spatial analysis, and save the results in `outputs/`.
